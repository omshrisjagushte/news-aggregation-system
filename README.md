# News Aggregation System

🚀 A modern, full-stack news aggregation platform with RSS feed support, user authentication, personalized categories, and advanced search functionality.

## Features

✨ **Core Features**
- 📰 RSS Feed Aggregation from multiple sources
- 🔐 User Authentication (JWT-based)
- 📂 Personalized Feed Categories
- 🔍 Advanced Search & Filtering
- ⭐ Save & Bookmark Articles
- 🎨 Dark/Light Mode Support
- 📱 Fully Responsive Design
- ⚡ Real-time Feed Updates
- 🏷️ Tag-based Organization
- 📊 Reading Statistics

## Tech Stack

### Backend
- Node.js + Express.js
- PostgreSQL Database
- JWT Authentication
- RSS Feed Parser
- Node-cron for scheduling

### Frontend
- React 18 + Vite
- Tailwind CSS
- Redux Toolkit
- React Router v6
- Axios

## Quick Start

### Using Docker Compose
```bash
docker-compose up -d
```

### Manual Setup
```bash
# Backend
cd backend && npm install && npm run dev

# Frontend (new terminal)
cd frontend && npm install && npm run dev
```

## Deployment
- **Frontend**: Vercel
- **Backend**: Railway/Render
- **Database**: PostgreSQL
